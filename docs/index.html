De OpenBOR a INPULSAR

Una idea que siguió creciendo.

OpenBOR Input Overlay nació como un proyecto open source para hacer visibles los controles durante partidas de OpenBOR. Esa idea evolucionó hacia INPULSAR, un ecosistema más amplio de overlays para gaming, grabación, streaming y creadores, desarrollado por Neon Pulsar Labs.

El proyecto original permanece disponible de forma independiente, con código fuente público, licencia MIT y sus propias descargas.

Lo esencial,
sin vueltas.

La documentación completa también está disponible en tres idiomas.

ESENPT
¿Necesito tener OBS instalado?

No. El overlay funciona por sí solo sobre OpenBOR. OBS solamente es necesario si querés grabarlo o transmitirlo.

¿Funciona con joystick o gamepad?

Sí. Acepta teclado y gamepads USB con mapping estándar al mismo tiempo. El stick izquierdo incluye zona muerta.

¿Por qué Windows muestra una advertencia?

El ejecutable todavía no tiene firma digital. Podés comparar su SHA-256 con el publicado en la release para verificar la descarga.

¿Puedo personalizar las teclas y el aspecto?

Sí. Podés reasignar todas las entradas, elegir skins, colores, intensidad, estela, tamaño, control direccional y distribución.

¿Dónde pido ayuda o reporto un problema?

Creá un issue en GitHub con tu versión de Windows, la versión de la app y una descripción de lo que ocurrió.
