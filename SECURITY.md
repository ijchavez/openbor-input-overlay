# Security policy

Please do not initially disclose a suspected vulnerability in a public issue or pull request.

If GitHub Private Vulnerability Reporting is available for this repository, use it to submit the report privately. Otherwise, request a secure reporting channel in a [GitHub issue](https://github.com/ijchavez/openbor-input-overlay/issues) without disclosing the vulnerability. Do not include exploit steps, affected details, logs, or other sensitive technical information in that issue. Wait for a private channel before sharing those details.

Security reports are assessed as maintenance time and priority allow. No response or fix time is promised.
